# Personal Portfolio

This is my personal portfolio website built to showcase my projects, skills, experience, and learning journey as a developer.

The portfolio was designed and developed by me using modern web technologies, with support from AI tools like ChatGPT and Grok for ideas, improvements, and productivity during the development process.

## Tech Stack

- React
- Tailwind CSS
- Framer Motion
- React Router

## Features

- Modern responsive UI
- Animated sections and illustrations
- Projects showcase
- Skills & experience timeline
- GitHub integration
- Certificates section
- Contact section

## Purpose

The goal of this portfolio is to reflect my work, continuous learning, and passion for building clean and interactive web applications.
